# 案例：挑选本地双语字幕工具

[返回首页](../README.md) · [English](subtitle-selection.en.md)

这是虚构案例，所有产品和 .invalid 网址均为模拟材料。它展示判断过程，不推荐真实产品。

## 处理前

请求：使用 Apple Silicon Mac，给私密产品演示视频生成中英双语 SRT。原视频本机处理，全流程免费；可下载模型。只读给定资料，不联网、不安装，也不要求预先实测。

收到六份摘录，涉及五个候选：

| 来源 | 原始描述摘要 |
|---|---|
| S1：WindowCaption README | Apple Silicon、macOS 13+，本地处理，1.8 GB 模型，同一 SRT 内双语 |
| S2：同项目导出文档 | 本地导出免费；付费协作是独立可选服务 |
| S3：NimbusSub | 免费注册，视频上传到服务器 |
| S4：VerseDesk | 本地处理免费，SRT 导出需 Pro |
| S5：MonoFrame | 免费本地处理，但中英文分别导出为两个单语文件 |
| S6：ShellSRT | 只有 Linux 步骤，识别提供方位置、费用及 Mac 支持不明 |

[完整原始材料](../validation/inputs/research.zh-CN.md)

## 处理后

WindowCaption 是基于给定文档的优先候选，**但必须先确认用户系统达到 macOS 13**。芯片信息不能代替系统版本。没有实际运行过，不能声称已经验证可用。

其他候选分别因上传原视频、导出收费、缺少完整双语流程而排除，或因关键证据缺失而待核实。S1 与 S2 归为同一资源，证据入口都保留。

| 需要作出的判断 | 本例如何处理 |
|---|---|
| 必须条件是否齐全 | 单独核对设备、数据位置、完整费用、同文件双语 SRT |
| 证据达到什么程度 | 给定文档摘录支持，不等于访问过网站或实测 |
| 付费功能是否一定排除 | 可选协作收费不影响已说明免费的本地导出路径 |
| 没有合适资源怎么办 | 只剩 S3–S6 时，没有合格推荐，不放宽条件 |
| 用户下一步做什么 | 先确认系统版本，再按需要核实下载与运行；本次不安装 |
