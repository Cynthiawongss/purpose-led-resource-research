# Worked example: local bilingual subtitles

[Home](../README.en.md) · [简体中文](subtitle-selection.md)

All products and .invalid URLs are fictional. This illustrates decisions, not real recommendations.

## Before

An Apple Silicon Mac user needs private demo videos processed on-device and Chinese-English subtitles in one SRT, with the complete workflow free. A model download is allowed. Only supplied material may be used; no browsing or installation. Prior runtime testing is not required for a documentation-based recommendation.

| Source | Raw claim |
|---|---|
| S1: WindowCaption README | Apple Silicon, macOS 13+, local processing, 1.8 GB model, bilingual SRT |
| S2: same project's export docs | Local export free; paid collaboration is optional |
| S3: NimbusSub | Free account, but upload required |
| S4: VerseDesk | Local editing free, SRT export paid |
| S5: MonoFrame | Free/local, but exports two separate monolingual files |
| S6: ShellSRT | Linux setup only; provider location, fees and Mac support unclear |

[Full source packet](../validation/inputs/research.en.md)

## After

WindowCaption is the documentation-supported priority candidate, **conditional on confirming macOS 13+**. Apple Silicon alone does not establish that condition. No runtime test occurred.

The other options fail privacy, cost or output requirements, or remain unresolved because critical information is absent. S1 and S2 form one candidate with two evidence entry points.

| Decision | Result |
|---|---|
| Required conditions | Device, data location, total cost and same-file bilingual output checked separately |
| Evidence level | Supplied excerpts, not live website inspection or runtime verification |
| Optional paid feature | Does not disqualify a separately documented free local workflow |
| No-fit follow-up | S3–S6 alone support no qualified recommendation |
| Next step | Confirm OS version, then investigate downloads/runtime only as needed and authorized |
